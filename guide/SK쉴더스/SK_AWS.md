# AWS 클라우드 취약점 판단 기준 (1.1 ~ 4.15) - 풀 텍스트

| 코드 | 점검항목 제목 | 판단 기준 (양호) | 판단 기준 (취약) |
|------|---------------|------------------|------------------|
| **1.1** | 사용자 계정 관리 | 관리자 권한을 보유한 다수 계정이 존재하지 않고 불필요한 계정이 존재하지 않을 경우 | 관리자 권한을 보유한 다수 계정이 존재하거나 불필요한 계정이 존재할 경우 |
| **1.2** | IAM 사용자 계정 단일화 관리 | IAM 사용자 계정을 1인 1계정으로 사용하고 있는 경우 | IAM 사용자 계정을 1인 1계정으로 사용하고 있지 않은 경우 |
| **1.3** | IAM 사용자 계정 식별 관리 | 사용자 정보(이름, 이메일, 부서 등)가 IAM 사용자 태그에 설정되어 있을 경우 | 사용자 정보(이름, 이메일, 부서 등)가 IAM 사용자 태그에 설정되어 있지 않을 경우 |
| **1.4** | IAM 그룹 사용자 계정 관리 | IAM 그룹에 포함된 사용자 계정 중 불필요한 계정이 존재하지 않을 경우 | IAM 그룹에 포함된 사용자 계정 중 불필요한 계정이 존재할 경우 |
| **1.5** | Key Pair 접근 관리 | Key Pair(PEM)를 통해 EC2 인스턴스에 접근할 경우 | Key Pair(PEM)가 아닌 일반 패스워드로 EC2 인스턴스에 접근할 경우 |
| **1.6** | Key Pair 보관 관리 | Key Pair(PEM) File의 보관 위치가 쉽게 유추할 수 없는 공간에 보관되어 있을 경우 | Key Pair(PEM) File 의 보관 위치가 다수 접근이 가능한 공용 공간(퍼블릭 S3, EC2 “ Admin Console(/)” 디렉터리 등)에 보관되어 있을 경우 |
| **1.7** | Admin Console 관리자 정책 관리 | Admin Console 계정을 서비스 용도로 사용하지 않는 경우 | Admin Console 계정을 서비스 용도로 사용하는 경우 |
| **1.8** | Admin Console 계정 Access Key 활성화 및 사용주기 관리 | AWS Admin Console 계정에 Access Key가 존재하지 않고 IAM 사용자 계정에 대한 Access Key 사용 주기가 60일 이내일 경우 | AWS Admin Console 계정에 Access Key가 존재하거나 IAM 사용자 계정에 대한 Access Key 사용 주기가 60일 초과일 경우 |
| **1.9** | MFA (Multi-Factor Authentication) 설정 | AWS 계정 및 IAM 사용자 계정 로그인 시 MFA가 활성화 되어 있을 경우 | AWS 계정 및 IAM 사용자 계정 로그인 시 MFA가 비활성화 되어 있을 경우 |
| **1.10** | AWS 계정 패스워드 정책 관리 | Admin Console 및 IAM 계정의 패스워드 복잡성 기준 준수 및 암호 만료/재사용 제한을 설정하고 있을 경우 | Admin Console 및 IAM 계정의 패스워드 복잡성 기준 준수 및 암호 만료/재사용 제한을 설정하고 있지 않을 경우 |
| **1.11** | EKS 사용자 관리 | EKS 리소스 접근을 위한 ConfigMap(RBAC) 내 인가된 사용자만 설정되어 있는 경우 | EKS 리소스 접근을 위한 ConfigMap(RBAC) 내 인가된 사용자만 설정되어 있지 않은 경우 |
| **1.12** | EKS 서비스 어카운트 관리 | 네임스페이스 또는 서비스 어카운트 설정 내 automountServiceAccountToken 값이 False 로 설정된 경우 | 네임스페이스 또는 서비스 어카운트 설정 내 automountServiceAccountToken 값이 True로 설정된 경우 |
| **1.13** | EKS 불필요한 익명 접근 관리 | ClusterRole에 system:anonymous, unauthenticated 그룹이 바인딩 되어있지 않는 경우 | ClusterRole에 system:anonymous, unauthenticated 그룹이 바인딩 되어 있는 경우 |
| **2.1** | 인스턴스 서비스 정책 관리 | 인스턴스 서비스 IAM 사용 권한이 각각 서비스 역할에 맞게 설정되어 있을 경우 | 인스턴스 서비스 IAM 사용 권한이 각각 서비스 역할에 맞지 않게 설정되어 있을 경우 |
| **2.2** | 네트워크 서비스 정책 관리 | 네트워크 서비스 IAM 사용 권한이 각각 서비스 역할에 맞게 설정되어 있을 경우 | 네트워크 서비스 IAM 사용 권한이 각각 서비스 역할에 맞지 않게 설정되어 있을 경우 |
| **2.3** | 기타 서비스 정책 관리 | 기타 서비스 IAM 사용 권한이 각각 서비스 역할에 맞게 설정되어 있을 경우 | 기타 서비스 IAM 사용 권한이 각각 서비스 역할에 맞게 설정되어 있지 않을 경우 |
| **3.1** | 보안 그룹 인/아웃바운드 ANY 설정 관리 | 보안 그룹 내 인/아웃바운드의 포트가 Any로 허용되어 있지 않을 경우 | 보안 그룹 내 인/아웃바운드의 포트가 Any로 허용되어 있을 경우 |
| **3.2** | 보안 그룹 인/아웃바운드 불필요 정책 관리 | 보안 그룹 인/아웃바운드 규칙 내 불필요한 정책(Source, Destination)이 존재하지 않는 경우 | 보안 그룹 인/아웃바운드 규칙 내 불필요한 정책(Source, Destination)이 존재하는 경우 |
| **3.3** | 네트워크 ACL 인/아웃바운드 트래픽 정책 관리 | 네트워크 ACL 내 인/아웃바운드에 대한 모든 트래픽이 허용되어 있지 않을 경우 | 네트워크 ACL 내 인/아웃바운드에 대한 모든 트래픽이 허용되어 있을 경우 |
| **3.4** | 라우팅 테이블 정책 관리 | 라우팅 테이블 내 ANY 정책이 설정되어 있지 않고 서비스 타깃 별로 설정되어 있을 경우 | 라우팅 테이블 내 ANY 정책이 설정되어 있거나 서비스 타깃 별로 설정되어 있지 않을 경우 |
| **3.5** | 인터넷 게이트웨이 연결 관리 | 인터넷 게이트웨이에 불필요하게 연결된 NAT 게이트웨이가 존재하지 않을 경우 | 인터넷 게이트웨이에 불필요하게 연결된 NAT 게이트웨이가 존재하는 경우 |
| **3.6** | NAT 게이트웨이 연결 관리 | 외부 통신이 필요한 리소스가 NAT 게이트웨이가 연결되어 있을 경우 | 목적이 확인되지 않은 리소스가 NAT 게이트웨이에 연결되어 있을 경우 |
| **3.7** | S3 버킷/객체 접근 관리 | 퍼블릭 액세스 차단이 설정되어 있거나, 퍼블릭 액세스를 허용할 경우 ACL을 버킷 소유자에게만 설정하고 있을 경우 | 퍼블릭 액세스 차단이 설정되어 있지 않고, ACL이 모든 사람, 외부계정 소유자로 설정하고 있을 경우 |
| **3.8** | RDS 서브넷 가용 영역 관리 | RDS 서브넷 그룹 내 불필요한 가용영역이 존재하지 않는 경우 | RDS 서브넷 그룹 내 불필요한 가용영역이 존재하는 경우 |
| **3.9** | EKS Pod 보안 정책 관리 | PSS Profile Baseline 및 PSA Audit 이상 설정을 적용해 사용하는 경우 | PSS 및 PSA 설정을 적용하여 사용하지 않거나 PSS Profile Privileged 및 PSA warn 설정을 적용해 사용하는 경우 |
| **3.10** | ELB(Elastic Load Balancing) 연결 관리 | ELB 제어 정책을 준수하고 있는 경우 | ELB 제어 정책을 준수하고 있지 않는 경우 |
| **4.1** | EBS 및 볼륨 암호화 설정 | EBS 및 볼륨 리소스에 암호화가 활성화되어 있을 경우 | EBS 및 볼륨 리소스에 암호화가 비활성화되어 있을 경우 |
| **4.2** | RDS 암호화 설정 | RDS 데이터베이스 암호화가 활성화되어 있을 경우 | RDS 데이터베이스 암호화가 비활성화되어 있을 경우 |
| **4.3** | S3 암호화 설정 | Amazon S3 키(SSE-S3)로 서버 측 암호화 사용 또는 SSE-KMS로 서버 측 암호화가 설정되어 있을 경우 | Amazon S3 키(SSE-S3)로 서버 측 암호화 사용 또는 SSE-KMS로 서버 측 암호화가 설정되어 있지 않을 경우 |
| **4.4** | 통신구간 암호화 설정 | 클라우드 리소스 통신 구간 내 암호화 설정이 되어 있는 경우 | 클라우드 리소스 통신 구간 내 암호화 설정이 되어 있지 않는 경우 |
| **4.5** | CloudTrail 암호화 설정 | CloudTrail 관련 로그 파일에 SSE-KMS 암호화 설정이 되어있을 경우 | CloudTrail 관련 로그 파일에 SSE-KMS 암호화 설정이 되어있지 않을 경우 |
| **4.6** | CloudWatch 암호화 설정 | 로그 그룹 생성 시 "KMS key ARN" 을 설정하여 사용하고 있는 경우 | 로그 그룹 생성 시 "KMS key ARN" 을 설정하여 사용하고 있지 않는 경우 |
| **4.7** | AWS 사용자 계정 로깅 설정 | AWS 사용자 계정(Console, IAM)의 로깅이 설정되어 있는 경우 | AWS 사용자 계정(Console, IAM)의 로깅이 설정되어 있지 않은 경우 |
| **4.8** | 인스턴스 로깅 설정 | CloudWatch 로그 스트림으로 보관하고 있는 경우 | CloudWatch 로그 스트림으로 보관하고 있지 않은 경우 |
| **4.9** | RDS 로깅 설정 | CloudWatch 로그 스트림으로 보관하고 있는 경우 | CloudWatch 로그 스트림으로 보관하고 있지 않은 경우 |
| **4.10** | S3 버킷 로깅 설정 | 로그를 보관하고 있는 버킷의 "서버 액세스 로깅"이 설정되어 있는 경우 | 로그를 보관하고 있는 버킷의 "서버 액세스 로깅"이 설정되어 있지 않은 경우 |
| **4.11** | VPC 플로우 로깅 설정 | VPC 플로우 로그 설정이 존재하는 경우 | VPC 플로우 로그 설정이 존재하지 않을 경우 |
| **4.12** | 로그 보관 기간 설정 | AWS 서비스 로그를 기준(최소 1년 이상)에 맞게 보관하고 있는 경우 | AWS 서비스 로그를 기준(최소 1년 이상)에 맞게 보관하고 있지 않은 경우 |
| **4.13** | 백업 사용 여부 | 클라우드 리소스 백업 정책이 존재하는 경우 | 클라우드 리소스 백업 정책이 존재하지 않는 경우 |
| **4.14** | EKS Cluster 제어 플레인 로깅 설정 | EKS Cluster 제어 플레인 로깅을 설정하여 유형 별 로그를 기록하고 있는 경우 | EKS Cluster의 유형 별 로그를 기록하고 있지 않는 경우 |
| **4.15** | EKS Cluster 암호화 설정 | 암호 암호화가 활성화 되어있는 경우 | 암호 암호화가 활성화 되어있지 않는 경우 |
