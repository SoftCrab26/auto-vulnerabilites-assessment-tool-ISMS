# DBMS 서버 취약점 판단 기준 (D-01 ~ D-26) - 풀 텍스트

| 코드   | 점검항목 제목                                      | 판단 기준 (양호)                                                                 | 판단 기준 (취약)                                                                 |
|--------|---------------------------------------------------|----------------------------------------------------------------------------------|----------------------------------------------------------------------------------|
| **D-01**  | 기본 계정의 비밀번호, 정책 등을 변경하여 사용     | DBMS 기본 계정의 초기 비밀번호 및 권한 정책을 변경하여 사용하는 경우            | DBMS 기본 계정의 초기 비밀번호 및 권한 정책을 변경하지 않고 사용하는 경우      |
| **D-02**  | 데이터베이스의 불필요 계정을 제거하거나, 잠금설정 후 사용 | 불필요한 DB 계정을 제거하거나 잠금 설정한 경우                                  | 불필요한 DB 계정이 존재하거나 잠금 설정이 되어 있지 않은 경우                   |
| **D-03**  | 비밀번호 사용 기간 및 복잡도를 기관의 정책에 맞도록 설정 | 기관 정책에 맞게 비밀번호 사용 기간 및 복잡도(길이, 문자종류 등)가 설정된 경우 | 비밀번호 사용 기간 및 복잡도가 기관 정책에 맞지 않게 설정된 경우                |
| **D-04**  | 데이터베이스 관리자 권한을 꼭 필요한 계정 및 그룹에 대해서만 허용 | 관리자(DBA) 권한이 꼭 필요한 최소한의 계정 및 그룹에만 부여된 경우             | 불필요한 계정이나 그룹에 DBA 권한이 과도하게 부여된 경우                        |
| **D-05**  | 비밀번호 재사용에 대한 제약 설정                  | 비밀번호 변경 시 이전 비밀번호 재사용을 제한하는 정책이 설정된 경우             | 비밀번호 재사용 제한 정책이 설정되어 있지 않은 경우                             |
| **D-06**  | DB 사용자 계정을 개별적으로 부여하여 사용         | DB 접근 시 사용자별로 서로 다른 개별 계정을 사용하는 경우                       | DB 계정을 공유하여 사용하는 경우                                                |
| **D-07**  | root 권한으로 서비스 구동 제한                    | DBMS 서비스가 root 계정 또는 root 권한이 아닌 별도 계정으로 구동되는 경우       | DBMS 서비스가 root 계정 또는 root 권한으로 구동되는 경우                        |
| **D-08**  | 안전한 암호화 알고리즘 사용                       | SHA-256 이상의 안전한 해시 알고리즘을 사용하는 경우                             | 취약한 암호화 알고리즘(MD5, SHA-1 등)을 사용하는 경우                           |
| **D-09**  | 일정 횟수의 로그인 실패 시 이에 대한 잠금정책 설정 | 로그인 실패 횟수 제한 및 계정 잠금 정책이 설정된 경우                           | 로그인 실패 시 잠금 정책이 설정되어 있지 않은 경우                              |
| **D-10**  | 원격에서 DB 서버로의 접속 제한                    | 원격에서 DB 서버로의 접속이 IP/호스트 기반으로 제한된 경우                      | 원격 접속 제한 설정이 되어 있지 않은 경우                                       |
| **D-11**  | DBA 이외의 인가되지 않은 사용자가 시스템 테이블에 접근할 수 없도록 설정 | 시스템 테이블에 일반 사용자 접근이 차단된 경우                                  | 일반 사용자가 시스템 테이블에 접근 가능한 경우                                  |
| **D-12**  | 안전한 리스너 비밀번호 설정 및 사용               | Oracle Listener에 강력한 비밀번호가 설정된 경우                                 | Listener 비밀번호가 설정되지 않았거나 기본값인 경우                             |
| **D-13**  | 불필요한 ODBC/OLE-DB 데이터 소스와 드라이브를 제거하여 사용 | 불필요한 ODBC/OLE-DB 드라이버가 제거된 경우                                     | 불필요한 ODBC/OLE-DB가 설치되어 있는 경우                                       |
| **D-14**  | 데이터베이스의 주요 설정 파일, 비밀번호 파일 등과 같은 주요 파일들의 접근 권한이 적절하게 설정 | 주요 DB 파일(설정, 비밀번호 파일 등)에 대해 일반 사용자 쓰기 권한이 제거된 경우 | 주요 DB 파일에 일반 사용자 쓰기 권한이 부여된 경우                              |
| **D-15**  | 관리자 이외의 사용자가 오라클 리스너의 접속을 통해 리스너 로그 및 trace 파일에 대한 변경 제한 | Listener 로그/trace 파일에 관리자 외 변경 권한이 없는 경우                      | Listener 로그/trace 파일에 일반 사용자 변경 권한이 있는 경우                    |
| **D-16**  | Windows 인증 모드 사용                            | SQL Server에서 Windows 인증 모드만 사용하거나 Mixed 모드에서 강력한 정책 적용   | SQL Server 인증 모드가 취약하게 설정된 경우                                     |
| **D-17**  | Audit Table은 데이터베이스 관리자 계정으로 접근하도록 제한 | Audit 테이블에 DBA만 접근 가능하도록 설정된 경우                                | 일반 사용자도 Audit 테이블에 접근 가능한 경우                                   |
| **D-18**  | 응용프로그램 또는 DBA 계정의 Role이 Public으로 설정되지 않도록 조정 | Public Role에 불필요한 권한이 부여되지 않은 경우                                | Public Role에 과도한 권한이 부여된 경우                                         |
| **D-19**  | OS_ROLES, REMOTE_OS_AUTHENTICATION, REMOTE_OS_ROLES를 FALSE로 설정 | OS_ROLES, REMOTE_OS_AUTHENTICATION, REMOTE_OS_ROLES가 FALSE로 설정된 경우       | 해당 옵션이 TRUE로 설정된 경우                                                   |
| **D-20**  | 인가되지 않은 Object Owner의 제한                 | Object Owner가 인가된 사용자만 사용하도록 제한된 경우                           | 인가되지 않은 Object Owner가 존재하는 경우                                      |
| **D-21**  | 인가되지 않은 GRANT OPTION 사용 제한              | GRANT OPTION이 일반 사용자에게 부여되지 않은 경우                               | GRANT OPTION이 불필요하게 부여된 경우                                           |
| **D-22**  | 데이터베이스의 자원 제한 기능을 TRUE로 설정       | RESOURCE_LIMIT이 TRUE로 설정된 경우                                             | RESOURCE_LIMIT이 FALSE로 설정된 경우                                            |
| **D-23**  | xp_cmdshell 사용 제한                             | xp_cmdshell이 비활성화된 경우                                                   | xp_cmdshell이 활성화된 경우                                                     |
| **D-24**  | Registry Procedure 권한 제한                      | Registry 관련 Procedure 권한이 제한된 경우                                      | Registry Procedure 권한이 과도하게 부여된 경우                                  |
| **D-25**  | 주기적 보안 패치 및 벤더 권고 사항 적용           | DBMS 최신 보안 패치가 주기적으로 적용된 경우                                    | 보안 패치가 적용되지 않은 경우                                                  |
| **D-26**  | 데이터베이스의 접근, 변경, 삭제 등의 감사 기록이 기관의 감사 기록 정책에 적합하도록 설정 | 감사(Audit) 기능이 기관 정책에 따라 활성화되고 기록되는 경우                    | 감사 기능이 비활성화되거나 정책에 맞지 않게 설정된 경우                         |

*(PDF 기준으로 D-01 ~ D-26까지 추출 완료. Oracle, SQL Server 등 주요 DBMS에 공통적으로 적용되는 항목 위주)*
