# 네트워크 장비 취약점 판단 기준 (N-01 ~ N-38) - 풀 텍스트

| 코드    | 점검항목 제목                              | 판단 기준 (양호)                                                                 | 판단 기준 (취약)                                                                 |
|---------|-------------------------------------------|----------------------------------------------------------------------------------|----------------------------------------------------------------------------------|
| **N-01**   | 비밀번호 설정                             | 관리자 계정의 기본 비밀번호를 변경하여 사용하는 경우                            | 기본 비밀번호를 그대로 사용하고 있는 경우                                       |
| **N-02**   | 비밀번호 복잡성 설정                      | 비밀번호 복잡성 정책(영문 대소문자, 숫자, 특수문자 조합 등)이 설정된 경우       | 비밀번호 복잡성 정책이 설정되지 않은 경우                                       |
| **N-03**   | 암호화된 비밀번호 사용                    | 계정 비밀번호가 암호화되어 저장되는 경우                                        | 비밀번호가 평문으로 저장되는 경우                                               |
| **N-04**   | 계정 잠금 임계값 설정                     | 로그인 실패 임계값이 설정되어 계정이 잠기는 경우                                | 로그인 실패 임계값이 설정되지 않은 경우                                         |
| **N-05**   | 사용자·명령어별 권한 설정                 | 사용자별로 최소 권한 원칙에 따라 권한을 차등 부여한 경우                        | 과도한 권한(관리자 권한)을 불필요하게 부여한 경우                               |
| **N-06**   | VTY 접근(ACL) 설정                        | VTY(원격 터미널) 접근 시 지정된 IP에서만 접근 가능하도록 ACL 설정된 경우        | VTY 접근에 대한 IP 제한(ACL)이 설정되지 않은 경우                               |
| **N-07**   | Session Timeout 설정                      | 세션 타임아웃이 적절한 시간(예: 10분 이하)으로 설정된 경우                      | 세션 타임아웃이 설정되지 않거나 너무 긴 경우                                    |
| **N-08**   | VTY 접속 시 안전한 프로토콜 사용          | Telnet 대신 SSH 등 암호화된 프로토콜만 허용하는 경우                            | Telnet 등 안전하지 않은 프로토콜을 허용하는 경우                                |
| **N-09**   | 불필요한 보조 입출력 포트 사용 금지       | AUX, Console 등 불필요한 보조 포트가 비활성화된 경우                            | 불필요한 보조 포트가 활성화된 경우                                              |
| **N-10**   | 로그인 시 경고 메시지 설정                | 로그인 화면에 불법 접근 경고 메시지가 설정된 경우                               | 경고 메시지가 설정되지 않은 경우                                                |
| **N-11**   | 원격로그 서버 사용                        | 로그를 별도의 원격 로그 서버로 전송하도록 설정된 경우                           | 로그를 장비에만 저장하고 원격 전송을 하지 않는 경우                             |
| **N-12**   | 주기적 보안 패치 및 벤더 권고사항 적용    | 주기적으로 보안 패치 및 펌웨어를 업데이트하는 경우                              | 보안 패치 적용이 미흡한 경우                                                    |
| **N-13**   | 로깅 버퍼 크기 설정                       | 로깅 버퍼 크기가 충분히 설정된 경우                                             | 로깅 버퍼 크기가 부족하여 로그가 유실될 수 있는 경우                            |
| **N-14**   | 정책에 따른 로깅 설정                     | 중요 이벤트에 대한 로깅 정책이 설정된 경우                                      | 로깅 정책이 미설정된 경우                                                       |
| **N-15**   | NTP 및 시간 동기화 설정                   | NTP 서버를 이용한 정확한 시간 동기화가 설정된 경우                              | 시간 동기화가 설정되지 않은 경우                                                |
| **N-16**   | Timestamp 로그 설정                       | 로그에 Timestamp(시간 정보)가 기록되도록 설정된 경우                            | Timestamp가 기록되지 않는 경우                                                  |
| **N-17**   | SNMP 서비스 확인                          | 불필요한 SNMP 서비스를 비활성화하거나 최소한으로만 사용하는 경우                | SNMP 서비스가 불필요하게 활성화된 경우                                          |
| **N-18**   | SNMP Community String 복잡성 설정         | SNMP Community String이 강력한 값으로 설정된 경우                               | 기본값("public", "private")을 사용하는 경우                                     |
| **N-19**   | SNMP ACL 설정                             | SNMP 접근에 ACL(접근제어)이 설정된 경우                                         | SNMP 접근 제어가 설정되지 않은 경우                                             |
| **N-20**   | SNMP Community 권한 설정                  | SNMP Community에 Read-Only 권한만 부여한 경우                                   | SNMP에 Read-Write 권한을 부여한 경우                                            |
| **N-21**   | TFTP 서비스 차단                          | TFTP 서비스가 비활성화된 경우                                                   | TFTP 서비스가 활성화된 경우                                                     |
| **N-22**   | Spoofing 방지 필터링 적용                 | IP Spoofing 방지 필터링(예: uRPF)이 적용된 경우                                 | Spoofing 방지 필터링이 적용되지 않은 경우                                       |
| **N-23**   | DDoS 공격 방어 설정 또는 DDoS 장비 사용   | DDoS 방어 설정 또는 전용 장비를 사용하는 경우                                   | DDoS 방어 조치가 미흡한 경우                                                    |
| **N-24**   | 사용하지 않는 인터페이스 비활성화         | 사용하지 않는 물리적/논리적 인터페이스를 shutdown한 경우                        | 사용하지 않는 인터페이스가 활성화된 경우                                        |
| **N-25**   | TCP Keepalive 서비스 설정                 | TCP Keepalive가 적절히 설정된 경우                                              | TCP Keepalive 설정이 부적절한 경우                                              |
| **N-26**   | Finger 서비스 차단                        | Finger 서비스가 비활성화된 경우                                                 | Finger 서비스가 활성화된 경우                                                   |
| **N-27**   | 웹 서비스 차단                            | 불필요한 웹 관리 서비스(HTTP)가 비활성화된 경우                                 | 웹 관리 서비스가 불필요하게 활성화된 경우                                       |
| **N-28**   | TCP/UDP small 서비스 차단                 | Small services(TCP/UDP 7, 9, 13, 19, 23 등)가 비활성화된 경우                   | Small services가 활성화된 경우                                                  |
| **N-29**   | Bootp 서비스 차단                         | BOOTP 서비스가 비활성화된 경우                                                  | BOOTP 서비스가 활성화된 경우                                                    |
| **N-30**   | CDP 서비스 차단                           | CDP(Cisco Discovery Protocol)가 비활성화된 경우                                 | CDP 서비스가 활성화된 경우                                                      |
| **N-31**   | Directed-broadcast 차단                   | Directed Broadcast가 차단된 경우                                                | Directed Broadcast가 허용된 경우                                                |
| **N-32**   | Source Routing 차단                       | Source Routing이 차단된 경우                                                    | Source Routing이 허용된 경우                                                    |
| **N-33**   | Proxy ARP 차단                            | Proxy ARP가 비활성화된 경우                                                     | Proxy ARP가 활성화된 경우                                                       |
| **N-34**   | ICMP unreachable, redirect 차단           | ICMP unreachable 및 redirect 메시지가 차단된 경우                               | ICMP 메시지가 허용된 경우                                                       |
| **N-35**   | identd 서비스 차단                        | identd 서비스가 비활성화된 경우                                                 | identd 서비스가 활성화된 경우                                                   |
| **N-36**   | Domain Lookup 차단                        | DNS lookup 기능이 비활성화된 경우                                               | Domain Lookup이 활성화된 경우                                                   |
| **N-37**   | pad 차단                                  | PAD 서비스가 비활성화된 경우                                                    | PAD 서비스가 활성화된 경우                                                      |
| **N-38**   | mask-reply 차단                           | ICMP mask-reply가 차단된 경우                                                   | ICMP mask-reply가 허용된 경우                                                   |

*(PDF 기준 N-01 ~ N-38까지 네트워크 장비 섹션 전체 반영)*
