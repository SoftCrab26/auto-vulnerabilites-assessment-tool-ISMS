# PC 취약점 판단 기준 (PC-01 ~ PC-18) - 2026 주통기

분류: 계정 관리(PC-01~03) / 접근 관리(PC-04~09) / 패치 관리(PC-10~11) / 보안 관리(PC-12~18)

| 코드 | 점검항목 제목 | 중요도 | 판단 기준 (양호) | 판단 기준 (취약) |
|------|--------------|--------|------------------|------------------|
| **PC-01** | 비밀번호의 주기적 변경 | 상 | 최대 암호 사용 기간이 90일 이하로 설정된 경우 | 최대 암호 사용 기간이 90일을 초과하거나 무제한으로 설정된 경우 |
| **PC-02** | 비밀번호 관리정책 설정 | 상 | 최소 암호 길이가 8자 이상이고 암호 복잡성이 설정된 경우 | 최소 암호 길이가 8자 미만이거나 암호 복잡성이 설정되지 않은 경우 |
| **PC-03** | 복구 콘솔에서 자동 로그온을 금지하도록 설정 | 중 | 복구 콘솔 자동 로그온이 사용 안 함으로 설정된 경우 | 복구 콘솔 자동 로그온이 허용된 경우 |
| **PC-04** | 공유 폴더 제거 | 상 | 기본 공유 및 불필요한 공유 폴더가 존재하지 않는 경우 | 기본 공유 폴더(C$, ADMIN$ 등) 또는 불필요한 공유가 존재하는 경우 |
| **PC-05** | 불필요한 서비스 제거 | 상 | 불필요한 서비스가 사용 안 함으로 설정된 경우 | 불필요한 서비스가 자동 시작으로 설정된 경우 |
| **PC-06** | 비인가 상용 메신저 사용 금지 | 하 | 비인가 상용 메신저가 설치되지 않은 경우 | 비인가 상용 메신저가 설치되어 있는 경우 |
| **PC-07** | 파일 시스템이 NTFS 포맷으로 설정 | 상 | 모든 고정 드라이브의 파일 시스템이 NTFS로 설정된 경우 | NTFS가 아닌 파일 시스템(FAT32 등)이 존재하는 경우 |
| **PC-08** | PC 내 하나의 OS만 설치(멀티 부팅 미사용) | 중 | PC 내 하나의 OS만 설치된 경우 | 멀티 부팅이 설정되어 있는 경우 |
| **PC-09** | 브라우저 종료 시 임시 인터넷 파일 폴더의 내용을 삭제하도록 설정 | 중 | 브라우저 종료 시 임시 인터넷 파일 폴더를 비우도록 설정된 경우 | 브라우저 종료 시 임시 인터넷 파일 폴더 비우기가 미사용인 경우 |
| **PC-10** | 주기적 보안 패치 및 벤더 권고사항 적용 | 상 | HOT FIX가 설치되어 있고 자동 업데이트가 비활성화되지 않은 경우 | HOT FIX가 없거나 자동 업데이트가 비활성화된 경우 |
| **PC-11** | 지원이 종료되지 않은 Windows OS Build 적용 | 상 | 지원이 종료되지 않은 Windows OS Build를 사용하는 경우 | 지원이 종료된 Windows OS Build를 사용하는 경우 |
| **PC-12** | Windows 자동 로그인 점검 | 상 | AutoAdminLogon이 비활성화되어 있거나 설정되지 않은 경우 | Windows 자동 로그온이 활성화된 경우 |
| **PC-13** | 바이러스 백신 프로그램 설치 및 주기적 업데이트 | 상 | 바이러스 백신 프로그램이 설치되어 있는 경우 | 바이러스 백신 프로그램이 설치되어 있지 않은 경우 |
| **PC-14** | 바이러스 백신 프로그램에서 제공하는 실시간 감시 기능 활성화 | 상 | 실시간 감시 기능이 활성화된 경우 | 실시간 감시 기능이 비활성화된 경우 |
| **PC-15** | OS에서 제공하는 침입차단 기능 활성화 | 상 | Windows 방화벽이 사용으로 설정된 경우 | Windows 방화벽이 사용 안 함으로 설정된 경우 |
| **PC-16** | 화면보호기 대기 시간 설정 및 재시작 시 암호 보호 설정 | 중 | 화면보호기 암호 보호가 설정되고 대기 시간이 10분 이하인 경우 | 화면보호기 암호 보호가 없거나 대기 시간이 10분을 초과하는 경우 |
| **PC-17** | CD, DVD, USB 메모리 등 이동식 미디어의 자동 실행 방지 | 상 | 이동식 미디어 자동 실행이 방지된 경우 | 이동식 미디어 자동 실행 방지가 설정되지 않은 경우 |
| **PC-18** | 원격 지원을 금지하도록 정책이 설정 | 중 | 원격 지원이 사용 안 함으로 설정된 경우 | 원격 지원이 허용된 경우 |
