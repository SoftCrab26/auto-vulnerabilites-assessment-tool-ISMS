# Windows 서버 취약점 판단 기준 (W-01 ~ W-??) - 풀 텍스트

| 코드   | 점검항목 제목                          | 판단 기준 (양호)                                                                 | 판단 기준 (취약)                                                                 |
|--------|---------------------------------------|----------------------------------------------------------------------------------|----------------------------------------------------------------------------------|
| **W-01**  | Administrator 계정 이름 변경 등 보안성 강화 | Administrator 계정 이름을 변경하고, Guest 계정을 비활성화한 경우                | Administrator 계정 이름을 변경하지 않거나, Guest 계정을 활성화한 경우           |
| **W-02**  | 불필요한 계정 제거                    | 불필요한 계정이 존재하지 않는 경우                                              | 불필요한 계정이 존재하는 경우                                                    |
| **W-03**  | 계정 잠금 임계값 설정                 | 계정 잠금 임계값이 10회 이하로 설정된 경우                                      | 계정 잠금 임계값이 설정되지 않았거나 10회 초과로 설정된 경우                     |
| **W-04**  | 비밀번호 정책 설정                    | 비밀번호 정책(길이, 복잡성, 만료 등)이 설정된 경우                              | 비밀번호 정책이 설정되지 않은 경우                                              |
| **W-05**  | 비밀번호 파일 보호                    | SAM 파일이 암호화되어 보호되는 경우                                             | SAM 파일이 암호화되지 않은 경우                                                 |
| **W-06**  | 원격 터미널 서비스 제한               | 원격 터미널 서비스(RDP) 접근이 제한된 경우                                      | 원격 터미널 서비스 접근이 제한되지 않은 경우                                    |
| **W-07**  | 불필요한 서비스 중지                  | 불필요한 서비스가 중지된 경우                                                   | 불필요한 서비스가 실행 중인 경우                                                |
| **W-08**  | 불필요한 공유 폴더 제거               | 불필요한 공유 폴더가 제거된 경우                                                | 불필요한 공유 폴더가 존재하는 경우                                              |
| **W-09**  | 공유 폴더 접근 권한 설정              | 공유 폴더에 Everyone 권한이 제거된 경우                                         | 공유 폴더에 Everyone 권한이 부여된 경우                                         |
| **W-10**  | 레지스트리 보호                       | 중요 레지스트리 키에 대한 접근 권한이 적절히 설정된 경우                        | 중요 레지스트리 키 접근 권한이 취약한 경우                                      |
| **W-11**  | IIS 서비스 보안 설정                  | IIS 서비스가 필요 시 최소 권한으로 운영되는 경우                                | IIS 서비스가 취약한 설정으로 운영되는 경우                                      |
| **W-12**  | SQL Server 보안 설정                  | SQL Server 계정 및 권한이 강화된 경우                                           | SQL Server 기본 계정 및 권한이 취약한 경우                                      |
| **W-13**  | 최신 보안 패치 적용                   | 최신 보안 패치가 적용된 경우                                                    | 보안 패치가 적용되지 않은 경우                                                  |
| **W-14**  | 방화벽 설정                           | Windows 방화벽이 활성화되고 적절한 규칙이 설정된 경우                           | Windows 방화벽이 비활성화되거나 규칙이 미설정된 경우                            |
| **W-15**  | 이벤트 로그 관리                      | 이벤트 로그 크기 및 보존 기간이 적절히 설정된 경우                              | 이벤트 로그 설정이 부적절한 경우                                                |
| **W-16**  | 원격 레지스트리 접근 제한             | 원격 레지스트리 접근이 제한된 경우                                              | 원격 레지스트리 접근이 허용된 경우                                              |
| **W-17**  | 자동 업데이트 설정                    | 자동 업데이트가 활성화된 경우                                                   | 자동 업데이트가 비활성화된 경우                                                 |
| **W-18**  | SNMP 서비스 설정                      | SNMP Community String이 강력한 값으로 설정된 경우                               | SNMP Community String이 기본값("public", "private")인 경우                      |
| **W-19**  | FTP 서비스 보안                       | FTP 서비스가 비활성화되거나 보안 설정이 적용된 경우                             | FTP 서비스가 취약한 상태로 활성화된 경우                                        |
| **W-20**  | Telnet 서비스 비활성화                | Telnet 서비스가 비활성화된 경우                                                 | Telnet 서비스가 활성화된 경우                                                   |
| **W-21**  | SMTP 서비스 보안                      | SMTP 릴레이 제한 및 인증 설정이 적용된 경우                                     | SMTP 릴레이가 제한되지 않은 경우                                                |
| **W-22**  | NetBIOS 및 SMB 설정                   | 불필요한 NetBIOS 및 SMBv1이 비활성화된 경우                                     | NetBIOS 또는 SMBv1이 활성화된 경우                                              |
| **W-23**  | RDP(원격 데스크톱) 보안               | RDP에 NLA(Network Level Authentication)가 활성화된 경우                         | RDP에 NLA가 비활성화된 경우                                                     |
| **W-24**  | Guest 계정 비활성화                  | Guest 계정이 비활성화된 경우                                                   | Guest 계정이 활성화된 경우                                                      |
| **W-25**  | PowerShell 보안 설정                  | PowerShell 실행 정책이 제한된 경우                                              | PowerShell 실행 정책이 제한되지 않은 경우                                       |
| **W-26**  | Windows Defender 설정                 | Windows Defender 실시간 보호가 활성화된 경우                                    | Windows Defender가 비활성화된 경우                                              |
| **W-27**  | UAC(User Account Control) 설정        | UAC가 활성화되고 적절한 레벨로 설정된 경우                                      | UAC가 비활성화된 경우                                                           |
| **W-28**  | 세션 시간 제한 설정                   | 세션 제한 시간이 적절히 설정된 경우                                             | 세션 제한 시간이 설정되지 않거나 너무 긴 경우                                   |
| **W-29**  | SNMP Community String 복잡성          | SNMP Community String이 강력한 값으로 설정된 경우                               | 기본값 또는 약한 Community String 사용                                           |
| **W-30**  | 로그온 경고 메시지 설정               | 로그온 시 경고 메시지가 설정된 경우                                             | 로그온 경고 메시지가 설정되지 않은 경우                                         |
| **W-31**  | 불필요한 프로토콜 비활성화            | 불필요한 프로토콜(IPX, NetBEUI 등)이 비활성화된 경우                            | 불필요한 프로토콜이 활성화된 경우                                               |
| **W-32**  | 시스템 복원 설정                      | 시스템 복원 기능이 적절히 관리되는 경우                                         | 시스템 복원이 취약하게 설정된 경우                                              |
| **W-33**  | 보안 로그 크기 설정                   | 보안 이벤트 로그 크기가 충분히 설정된 경우                                      | 보안 이벤트 로그 크기가 부족한 경우                                             |
| **W-34**  | NTFS 권한 설정                        | 중요 디렉터리에 NTFS 권한이 적절히 설정된 경우                                  | NTFS 권한 설정이 취약한 경우                                                    |
| **W-35**  | 백신 프로그램 설치 및 업데이트       | 백신 프로그램이 설치되고 최신 업데이트된 경우                                   | 백신 프로그램이 설치되지 않았거나 업데이트되지 않은 경우                        |
| **W-36**  | 공유 자원 접근 통제                   | 공유 자원에 대한 접근 통제가 설정된 경우                                        | 공유 자원 접근 통제가 미흡한 경우                                               |
| **W-37**  | 레지스트리 접근 권한                  | 중요 레지스트리 키 접근 권한이 Administrator로 제한된 경우                      | Everyone 또는 일반 사용자에게 접근 권한이 부여된 경우                           |
| **W-38**  | 서비스 권한 설정                      | 서비스 권한이 최소한으로 설정된 경우                                            | 서비스 권한이 과도하게 부여된 경우                                              |
| **W-39**  | 자동 실행 설정                        | 불필요한 자동 실행 항목이 제거된 경우                                           | 불필요한 자동 실행 항목이 존재하는 경우                                          |
| **W-40**  | 취약한 암호화 알고리즘 사용 금지      | 강력한 암호화 알고리즘(예: AES, SHA-2)만 사용되는 경우                          | 취약한 암호화 알고리즘(RC4, MD5 등) 사용                                         |
| **W-41**  | RDP 포트 변경                         | RDP 기본 포트(3389)가 변경된 경우                                               | RDP 기본 포트가 그대로 사용되는 경우                                            |
| **W-42**  | 이벤트 로그 감사 정책                 | 중요한 이벤트에 대한 감사 정책이 설정된 경우                                    | 감사 정책이 설정되지 않은 경우                                                  |
| **W-43**  | 로그 파일 접근 통제                   | 로그 파일에 대한 접근 권한이 Administrator로 제한된 경우                        | 로그 파일에 Everyone 권한이 부여된 경우                                         |
